# Security policy

## Reporting a vulnerability

Do not disclose security or privacy vulnerabilities in public Issues.

Use the repository's **Security → Report a vulnerability** option so the maintainers can discuss the issue privately. Include reproduction steps using fictional data only.

Do not include patient information, credentials, access tokens, private URLs or production data in a report.

## Supported version

Only the latest version on the `main` branch is supported during the prototype phase.
