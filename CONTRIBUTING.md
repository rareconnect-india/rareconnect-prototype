# Contributing to the RareConnect prototype

Thank you for helping improve RareConnect.

## Workflow

1. Create a short branch from `main`, such as `feature/community-filter` or `fix/mobile-overflow`.
2. Keep each change focused and test it on desktop and a mobile-width viewport.
3. Open a pull request describing the user problem, the change and how it was tested.
4. Obtain at least one review before merging.

Do not push directly to `main`, force-push shared branches or commit generated build output.

## Safety and privacy

This is a public repository. Do not include:

- Real patient or caregiver information
- Names, phone numbers, email addresses or precise locations
- Diagnoses, medical histories, reports, prescriptions or photographs
- Interview transcripts, tester lists or moderation cases
- Passwords, tokens, API keys or private infrastructure details

Use fictional seeded data in screenshots, fixtures and demonstrations. Product copy must not imply medical advice, emergency response, treatment eligibility, government-scheme eligibility or submission on a user's behalf.

## Pull-request checks

- First-run onboarding completes successfully.
- Posting, community joining, connections and messaging still work.
- Report and block controls remain visible and functional.
- No horizontal overflow appears at desktop or 375px mobile width.
- Browser console contains no errors.
- All assets work from the `/rareconnect-prototype/` GitHub Pages subpath.

By contributing, you confirm that you have permission to submit your work. This repository currently has no open-source license.
